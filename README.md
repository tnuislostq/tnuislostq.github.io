## 🎨 Design System & UI Highlights

The portfolio features a modern **Liquid Glass (Frosted Glassmorphism)** aesthetic with cyber-minimalist dark styling:

* **Frosted Glass Cards:** Translucent surfaces with hardware-accelerated blur (`backdrop-filter: blur(16px)`), neon cyan borders (`#00F2FE`), and ambient background radial glow orbs.
* **Continuous Marquee Tape:** Infinite horizontal ribbon introducing core roles and technology domains.
* **Dual Theme Switcher:** Integrated toggle between high-contrast **Obsidian Dark Glass** (default) and **Frost Light Glass**, saved across sessions via `localStorage`.
* **Typographic Hierarchy:** Modern sans-serif pairings (*Space Grotesk* for headlines, *Plus Jakarta Sans* for body copy, and *JetBrains Mono* for technical metrics).
