## 🚀 How to Deploy to GitHub Pages (`tnuislostq.github.io`)

This repository comes pre-configured with **GitHub Actions** for 100% automated continuous deployment.

### Option 1: Automatic Deployment via GitHub Actions (Recommended)

1. **Push this code to your repository**:
   ```bash
   git add .
   git commit -m "Deploy modern full-stack developer portfolio"
   git remote add origin https://github.com/tnuislostq/tnuislostq.github.io.git
   git branch -M main
   git push -u origin main --force
   ```

2. **Enable GitHub Actions in your repository settings**:
   - Go to your repository on GitHub: `https://github.com/tnuislostq/tnuislostq.github.io`
   - Click **Settings** (⚙️) tab at the top
   - In the left sidebar, click **Pages**
   - Under **Build and deployment** > **Source**, change the dropdown from **Deploy from a branch** to **GitHub Actions**
   - That's it! GitHub Actions will run the `.github/workflows/deploy.yml` workflow automatically and deploy your site to `https://tnuislostq.github.io/` in ~60 seconds.
